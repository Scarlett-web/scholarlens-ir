# 当前功能范围与保存边界

日期：2026-10-29；正式模式已连接真实 API，不能继续沿用最初 demo 阶段的“待接 BM25 / 无账户”描述。

| 模块 | 当前功能 | 保存/依赖边界 |
| --- | --- | --- |
| 搜索 | 六字段、三模式、建议、年份、排序、分页、URL 分享和范围高亮 | ES；semantic 的字段范围受 API 限制 |
| 论文 | 摘要、正文查找/展开、专注、位置、选文、引用、原 PDF | PDF 原件独立存储；位置是本机记录 |
| 首页 | 首屏搜索、真实最近五篇、可控制的 3D 卡片 | 不用虚构阅读填满 |
| 探索 | 候选、换批、真实字段关系图 | 不是引用图或自动推荐模型 |
| 我的文献 | 收藏分类、笔记、历史、JSON 备份 | 游客本地；登录服务端；导入会替换当前空间 |
| 账户 | 注册登录退出、资料头像、安全、通知 | 私人数据后端校验所有权 |
| 本地 PDF | 校验、存储、预览、本机审核 | IndexedDB，不代表正式入库 |
| API 上传 | 登录上传、审核、处理、独立增量索引、归档 | 管理员审核；202 不等于索引完成 |
| 评测 | 0/1/2 标注、Precision/nDCG、导出 | 未完成标注不制造指标 |
| 助手 | 原文证据、个人 API、自然语言追问、总结比较、会话 | 两协议、引用核验、通用回答明确标签 |
| 显示设置 | 三档玻璃、暂停动效、展示模式 | 浏览器偏好，不改变学术数据 |

18 篇合成样本仅用于明确标记的 demo；生产由 `build:production` 固定到 API。主下载按钮是 PDF，兼容 DOCX API 保留但不作为页面主下载。邮件、XML、正式中文多语言语义仍有边界。

逐项使用与实现见[总报告](../../PROJECT_REPORT.md)，具体接口见[API 契约](../../specs/04_API_CONTRACT.md)。

## 2026-11-03 助手输入框提交行为

- 输入与输出：有效问题提交后立即清空输入框，使用提交瞬间的文本快照发送；等待时仍显示已提交的问题，可编辑下一条草稿，但当前请求结束前不重复发送。
- 失败与停止：输入框为空时恢复本次提交前的原始草稿；已有新草稿则保留新内容。回答完成或已停止请求的迟到结果不得清空、覆盖下一条草稿；原文检索仍保留检索词。
- 负责人：组长维护前端交互。验收：独立 Chrome 的受控延迟/失败/停止、键盘提交、总结/比较、桌面及 390px 手机界面回归，并完成构建、单元与结构检查；Mock 验收不代表真实模型生成成功。
