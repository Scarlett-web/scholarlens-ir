## 构建与数据模式

- 在 frontend 运行 `npm run typecheck`、`npm run test`、`npm run verify:structure`。
- 发布使用 `npm run build:production`，核对 build-info 的 `api`、`/api` 和所有资源 hash。
- 正常 demo 使用 18 篇明确虚构样本；正式验收必须看到真实论文及 `status=real`。
- 浏览器回归需要明确 owned preview 与 API 来源。旧账户浏览器脚本有隔离挑战守卫，不能直接对生产写入。

## 桌面主要路径

| 页面 | 核对重点 |
| --- | --- |
| 导航 | 顶部 Dock、工具悬停/离开/点击固定/选项跳转、键盘与焦点 |
| 首页 | 1366×768 首屏搜索、真实最近五篇、空状态、翻页、暂停/减少动态 |
| 搜索 | 字段/模式限制、年份、排序、建议键盘、URL/页码、错误重试、无横向溢出 |
| 详情 | 长 ID 换行、摘要/正文、专注/退出、位置恢复、选文笔记、原 PDF 阅读与下载（DOCX 为兼容后端能力） |
| 探索/关系 | 当前候选真实字段、无伪造边、focus 保留/退出/前后退、换批和迟到响应 |
| 书架 | 分类/笔记、初次加载/失败/重试、同步失败保留、导入确认、导出 |
| 账户 | 登录注册、错误二次凭证不退出、真实会话失效、资料/头像/通知、跨用户隔离 |
| 证据台 | 无模型证据、引用/Unicode 范围、原文变化/失败、重试、笔记追加、配置脱敏、两协议/列表/测试/保存状态、对话区与底部输入 |
| 上传/审核 | 私人/管理角色、真实状态、同上下文失败保留、切换清除、预览迟到隔离 |
| 评测 | 未标注不出分、部分/完整前缀、0/1/2、真实耗时、导出 |

## 验证边界

Chrome/Edge 桌面 1440/1366 为主要布局范围；390px 只做回归。截图必须等数据、滚动和入场稳定再查看，不把 DOM 存在当视觉验收。不要为截图制造论文/指标，也不要在生产注册测试账户、写笔记、上传或扫描。

本机隔离检查、真实 API 游客检查、公网只读检查分别记录。指定模型已有独立真实生成证据，其他供应商可用性、邮件投递、全键盘/读屏、Mac 原生浏览器、正式全库解析质量和并发容量需要独立证据。
