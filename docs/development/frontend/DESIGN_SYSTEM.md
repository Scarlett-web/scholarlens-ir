# ScholarLens 当前界面与交互规范

日期：2026-10-29；按外观基线 `d7cfc56` 记录。此文档说明现状，不授权额外修改界面。设计由用户迭代确认，Skill 仅为参考。

## 当前视觉和导航

冰岛冰川/海面实景为背景，明亮白玻璃、深色文字和蓝色操作强调；使用系统字体。桌面主入口为顶部 Dock，包含首页、论文检索、探索论文、我的文献，辅助入口收进“研究工具”下拉。下拉可悬停打开、延迟关闭、点击固定，点击目的项后收起。

原侧栏、旧白玻璃数值和旧演示首屏仅作为历史设计。当前页面层级以 `Layout.tsx`、`App.tsx` 和 canonical CSS 为准，不从旧截图恢复样式。

## 材质和层级

| 档位 | 内部值 | 卡片白底 alpha | 背景模糊 |
| --- | --- | ---: | --- |
| 纯白通透 | clear | .45 | 28px / saturate(1.35) |
| 标准微霜 | soft | .62 | 20px / saturate(1.25) |
| 凝脂厚雾 | solid | .88 | 16px / saturate(1.15) |

新浏览器缺省 clear；用户已保存的选择继续保留。alpha 只是当前卡片变量，不代表所有嵌套元素最终的计算透明度。变量集中在 `frontend/src/design-core.css`，场景布局在现有 `design-pages.css` / `design-workspaces.css` 等层内；本次不追加覆盖表。

## 各页面

首页突出首屏搜索、3D 研究卡与最多五篇真实最近阅读。助手采用主对话区和底部输入框，“阅读方式 / 对话记录 / API 设置”按需展开。我的文献用整片磨砂卡和横向分类胶囊，减少多重框线。阅读页保留正文、专注模式和原 PDF 入口，清晰阅读优先于材质展示。

装饰不编码学术统计。界面静态修辞不能用作速度/数据规模的实验证据；数量来自 API、性能来自明确条件下的测量。

## 动效与交互

现有 CSS 3D 倾角、层叠阅读卡、光影、悬停与点击反馈保持。全站暂停、系统减少动态、离屏和标签页状态继续控制动效。输入框保持首屏可操作；键盘焦点、Escape 关闭与输入法选词不误发送是功能边界。

桌面优先；已有移动结构只作为回归，不扩展移动设计任务。当前历史验证不能据此宣称全 WCAG 或所有设备已验收。
