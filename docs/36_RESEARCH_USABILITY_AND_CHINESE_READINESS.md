## 输入、输出与验收条件

- 用户可自由输入中文、自然语言及追问，不要求按检索语法提问。有本库证据时仍逐字验证引用；未找到证据且未限定具体论文的普通问答可生成通用回答，明确标注“未由本库文献验证”，不能冒充已读论文。单篇总结与多篇比较继续尊重所选范围；模型故障显示固定的脱敏原因，不据此要求用户改写问题。
- 个人 API 的 URL、模型、密钥仍按既有账户/标签页边界保存。配置区默认可发现，提示密钥的会话保存规则；不读取、写入或提交用户现有密钥。
- 桌面对话区获得主要垂直空间；侧栏辅助设置紧凑排列，默认折叠不常用部分。保留全部控制项、来源和取消操作。
- 作者、日期、机构、地址、标题、正文检索返回并显示实际字段的高亮；仅解释服务端 em 标记，以 React 文本渲染，不注入 HTML。全文命中显示标注为“全文命中”的片段，避免与摘要混淆。
- 论文详情与服务器上传队列的下载按钮改为下载 PDF 原件，继续使用原有鉴权 PDF 读取路径；不删除兼容 DOCX API。
- 后续新索引 generation 准备内置 CJK 双字分词辅助字段，中英混合查询可使用它；原有英文字段与排名行为保留，当前生产论文/向量不重建、不切别名。新增中文字段的真实检索须通过独立测试索引验证。当前英文 MiniLM 不被宣称为中文或跨语言模型；未来需独立评估多语言模型并重建独立向量 generation。

## 实现与兼容边界

普通问答先检索原文。没有可核对来源，或模型明确返回证据不足时，可调用通用回答；错误引用不会转成已验证回答。通用回答以 `evidence_status=general_answer` 返回，`citations=[]`、`agent.grounded=false`，保存和重开对话均保留未验证标签。认证失败、额度、超时、协议格式错误显示固定脱敏提示，不回显上游错误正文。

`/api/agent/run` 兼容原请求，增加可选 `context_messages`：最多 12 条、每条最多 1000 字符，仅接受 user/assistant。临时对话发送本轮之前的上下文；指定已保存对话时以服务器验证所有权后的记录为准。上下文用于理解追问，不能充当引用来源。问答方式和论文范围可继续切换。

对话区高度跟随桌面可用高度，页头与输入区压缩留白；右侧“论文范围”“对话记录”折叠，个人 API 未填时展开、保存后收起。保留全部按钮、停止操作和证据入口；白玻璃与背景透明度变量保持。

检索响应新增有默认值的 `date`、`affiliation`、`address`，关键词、语义及混合模式均兼容。结果行实际展示并安全高亮各字段。服务端仅提供 em 作为高亮分隔，前端通过 React 文本节点渲染；全文命中单独标记。下载使用原鉴权 PDF 接口，文件后缀与内容一致，不再触发 DOCX 转换。

后端 mapping 版本 `papers-v2-cjk` 为新 generation 的六个字段和摘要增加内置 `cjk` 辅助字段。遇到汉字时附加辅助查询，结果字段和高亮归并回原字段；无辅助字段的旧 generation 仍可检索。当前正式索引保持旧版本，本次不迁移现有数据。后续中文文件应保留 UTF-8 元数据与可提取文本；扫描 PDF 仍需 OCR，中文语义能力需另行选择和验证多语言模型。CJK 辅助索引会增加后续新 generation 的磁盘占用，建库前需评估。
