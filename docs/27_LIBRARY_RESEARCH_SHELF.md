# 研究书架与账户文献读取契约

2026-10-28。负责人：项目维护者。参考 GPT Pro 文献库建议，延续真实收藏、分类、笔记和阅读位置；桌面优先，390px 仅回归。输入为现有收藏、浏览历史与本机阅读位置，输出为可操作的研究书架及明确的数据读取状态，不增加虚构论文、进度或后端字段。

## 行为与验收条件

- 分类以横向书签表达，保留创建、重命名、删除及未分类规则。分类删除仍需原有确认，论文移回未分类；筛选和排序语义保留。纸张层次仅作为装饰，论文标题、原有链接和按钮保持稳定可读，暂停及减少动态效果时关闭装饰位移。
- 文献与其私人笔记在桌面并列，笔记仍可展开编辑和自动保存。真实阅读位置和本机标识保留；顶部继续阅读仅来自实际浏览历史，无记录时不伪造推荐或阅读百分比。
- 账户空间加载时显示读取状态，不显示零收藏或空书架作为已知结果；初次读取失败显示错误和明确重试。重试只重新 GET 当前账户空间，取消已废弃请求，账户切换后旧响应不能写入新空间。
- 已加载空间的同步失败与初次读取失败区分。保留当前文献与本机恢复草稿，显示同步失败并允许导出；不通过自动重新读取覆盖未同步内容，不自动重复提交失败写入。仅在尚未加载成功时允许读取重试。
- 未完成读取或同步失败时阻止文献写入控件，阅读链接与导出已知数据仍可用。账户导入的确认文字明确说明将替换当前账户空间并同步服务器，游客导入明确是当前浏览器空间；不改变备份 JSON 格式。
- 保留收藏、搜索、笔记、最近阅读、分类、备份导入导出和账户隔离。只编辑 canonical CSS，沿用系统字体、现有图标和材质，不增加依赖或全局配置。
