## 1. 优化背景与用户核心诉求

此前界面存在以下问题：
1. **AI 味道浓重与卡片死板堆积**：大量纯白高不透明度矩形框（`background: #fff` 或 `#f9fdffe0`）层层叠盖在冰川湖背景上，完全阻断了背景景深，显得僵硬扁平。
2. **按钮排布与视觉层级平淡**：按钮缺乏触觉质感与明确的主次层级，交互缺少物理弹性反馈。
3. **主页信息杂乱**：存在过多零散的线框标注与次要文本，缺少苹果式现代高端产品所需的“少而精”极简气度。
4. **透明度调节无法穿透至卡片**：虽然顶层提供了玻璃通透度开关，但卡片硬编码白色导致“通透模式”下核心卡片依然呈现不透明的白块。

用户明确指示：
- 设计高级感、动态 3D 动画、苹果圆角风格（Apple Squircle）；
- 玻璃质感纯透明且可调节透明度，底层大海/冰川背景自然透视；
- 主页布局重新梳理，突出主题，简洁美、高级感、少而精；
- 严禁破坏现有业务逻辑、API 契约、搜索参数与功能。

## 2. 核心架构重构与视觉规范

### 2.1 真·动态毛玻璃体系（Glassmorphism Engine）
- 在 `src/design-core.css` 中确立了统一的动态卡片玻璃变量：
  - `--glass-card-bg`: 基础透明背景
  - `--glass-card-border`: 细晶高光边缘（`rgba(255, 255, 255, 0.75)`）
  - `--glass-card-rim`: 顶部镜面内高光（`inset 0 1px 1px 0 rgba(255, 255, 255, 0.95)`）
  - `--glass-card-shadow`: 纵深柔光阴影（`0 16px 44px -10px rgba(15, 45, 75, 0.12)`）
  - `--glass-card-blur`: `blur(20px) saturate(1.35)`
- 三档通透度与 `[data-glass]` 全局联动：
  - **通透（Clear）**：`--glass-card-bg: rgba(255, 255, 255, 0.38)`，冰川湖水与冰山轮廓清晰透出，晶莹剔透。
  - **标准（Soft）**：`--glass-card-bg: rgba(255, 255, 255, 0.62)`，平衡水体景深与文字对比度。
  - **厚雾（Solid）**：`--glass-card-bg: rgba(255, 255, 255, 0.88)`，呈现细腻的白瓷磨砂质感。

### 2.2 蓝宝石与流光液态玻璃按钮系统（Apple Button Hierarchy）
- **主要操作（Primary Button）**：
  - 蓝宝石渐变：`linear-gradient(180deg, #1882ea 0%, #0866c6 100%)`
  - 顶边内嵌微光：`box-shadow: inset 0 1px 0 rgba(255,255,255,0.35), 0 6px 18px rgba(8,102,198,0.32)`
  - 物理微弹性反馈：`:active` 触发 `transform: scale(0.97)`
- **次要操作（Liquid Frosted Glass Pill）**：
  - 半透磨砂液态玻璃：`background: rgba(255, 255, 255, 0.65)` 配合 `backdrop-filter: blur(12px)`
  - 悬浮上浮与微光扩展：悬停时轻微上浮 1px，投影与边框高光同步加强。

### 2.3 动态 3D 透镜空间与探索工件（3D Research Artifact）
- 主页右侧 3D 舞台支持随光标实时跟踪的微视差倾角交互（`rotateX` / `rotateY`）；
- 阅读历史不为空时：呈现 3D 层叠阅读卡片，带有平滑的翻页物理动画；
- 阅读历史为空（初次进入）时：告别简陋的空白死板文字框，升级为**“3D 透镜探索视窗”**：
  - 呼吸浮动的光影核心图章；
  - 胶囊透镜标识（`✦ 18+ 经典论文库 · 毫秒级原文定位 · 多维证据链核查`）；
  - 蓝宝石快捷检索入口。

### 2.4 主页极简高端排版（少而精布局）
- 顶部升级为高规格苹果风格浮动胶囊徽标：`✦ ScholarLens / 学术文献确定性检索与核验引擎`；
- 主标题采用深海蓝宝石渐变字：`探寻学术前沿，在原文中核验确定性。`；
- 检索条重塑为悬浮式圆角玻璃控制台（Squircle `border-radius: 22px`），集成字段筛选与聚焦辉光；
- 底部精选两扇玻璃视窗：**前沿研究领域**（编号角标 `01`, `02`, `03`）与**个人研究空间**，去除非必要视觉杂质。
