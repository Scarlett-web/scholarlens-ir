用户明确要求将最新分支完整同步到本地并更新既有华为云服务。本轮以 `jwj` 的 `1660f60` 为来源，恢复 `zjl` 中此前撤回的扩库代码，再合入拼写建议和助手更新；保留双方 Git 历史，不强推。

## 应用更新与数据交付是两件事

4000 篇接入代码已包含在来源分支，但扩库的准备文件、236947 条向量和新增 3141 份 PDF 不在源码中。本机未找到分支文档所述 `output/corpus-expansion/prepare-02`、`index-04` 和新 PDF 目录。数据分支提供新增 JSONL 的 Git LFS 对象与来源 CSV；GitHub 原件 Release 目前仅有旧批原包。

因此本轮应用更新继续使用服务器已验收的 859 篇关键词、49420 个向量片段和 859 份原始 PDF。不声称 4000 篇已在线、不将旧向量配到新关键词库，也不将文本可读当成新原件已经交付。扩库应在配套文件可用后独立生成并校验新代，再切换对应配置。
