# 首页研究棱镜与专注阅读

负责人：项目维护者。参考 GPT Pro 设计记录的首页、材料、阅读与动效建议，保留现有检索、最近五篇翻页、收藏和 PDF 操作。

## 实现契约

- 首页：装饰性的低多边形冰晶有透光面、厚度和边缘反射；复用现有鼠标视差、暂停、离屏和系统减少动态效果控制。冰晶不表示论文引用关系，不填虚构数据。搜索仍须在 1366×768 桌面首屏可见，最近阅读只展示实际看过的至多五篇。
- 材料：导航及主视觉使用清澈玻璃，控制使用磨砂层，正文使用实色纸面；阅读区不透出背景照片。保持系统字体与既有设计令牌，不引入图形或动效常驻依赖。
- 阅读：提供可退出的专注模式、真实页面区域导航、当前展开内容的滚动进度，以及主动恢复上次位置的入口。没有结构化章节的数据只标记“摘要、正文、文献信息、参考工具”，不编造章节、页码或完成阅读状态。
- 位置记忆：仅在当前浏览器保存论文 ID、滚动比例、展开状态、文本长度与时间；按游客/用户 ID 隔离，最多 100 篇。不自动跳走，不将本地位置描述为跨设备同步；存储失败明确反馈。
- 原文摘录：只接受正文或摘要内真实选中的文本。复制或追加到原有文献笔记；未收藏时一并收藏，保留已有笔记，容量不足时拒绝并提示，不静默截断。账户笔记沿用既有同步和失败提示。
- 保留：全文查找、折叠、原 PDF、DOCX、引用复制导出、收藏与分享保持可用。专注模式有明确退出按钮和 Escape 退出，键盘焦点可见。

## 验收条件

运行构建、单元测试和结构检查；浏览器验证首屏几何、视差与暂停、最近五篇、专注/退出、导航、真实进度和位置恢复、原文摘录不覆盖已有笔记。保存桌面与 390px 几何截图，手机仅做回归。生产仅做只读验收，不注册审计用户或向账户写测试数据。

代码验证通过后提交推送并部署既有华为云服务，保留回滚版本和一致性备份。工具输出、截图和局部安装依赖保留在忽略目录。检查结果与发布证据在完成后补记；此文档不代表其余逐页设计和安全审计任务已经完成。
