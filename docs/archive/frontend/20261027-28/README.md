# 前端历史设计与验收

本目录保存 11 份设计迭代和验收快照。它们用于回看用户反馈、旧版布局、玻璃材质/动效演变和早期验证，不作为当前功能是否完成的依据。原截图/备份路径保留原意，其中很多属于旧工作区忽略目录，不能从 Git 克隆自动获得。

- [UI_REFRESH](UI_REFRESH_20261027.md)、[UI_REFRESH_V6](UI_REFRESH_V6_20261027.md)：早期版式与研究工作区调整。

- [UI_GLACIER_OBSERVATORY](UI_GLACIER_OBSERVATORY_20261027.md)、[UI_CLEAR_GLASS](UI_CLEAR_GLASS_20261027.md)：冰岛照片、玻璃材质和容器精简。
- [UI_AUDIT](UI_AUDIT_20261027.md)、[GLOBAL_AUDIT](GLOBAL_AUDIT_20261028.md)、[UX_POLISH](UX_POLISH_20261028.md)：当时的问题与调优证据。
- [DESKTOP_API_ACCEPTANCE](DESKTOP_API_ACCEPTANCE.md)：旧桌面真实 API 验收快照。
- [QA_CHECKLIST_20261027](QA_CHECKLIST_20261027.md)：旧累计 QA 记录。

当前页面与检查入口为[前端说明](../../../../frontend/README.md)、[当前 QA 清单](../../../development/frontend/QA_CHECKLIST.md)、[设计规范](../../../development/frontend/DESIGN_SYSTEM.md)和[项目总报告](../../releases-20261028-29/PROJECT_REPORT_20261028.md)。`DESIGN_SKILL_AUDIT.md` 仍在原位置：它是结构检查明确依赖的参考记录，未作为“无用说明”移动。
