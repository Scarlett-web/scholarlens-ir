# ScholarLens V6 · 研究工作区整体升级

本轮按用户“大胆一些，把整个都做高级一些”的要求升级现有界面。沿用项目内 redesign-existing-projects 与 landing-page-design 的诊断方法，服从学术产品与 Apple / macOS 浅色要求。

## 最终变化

- 桌面导航从横向页头改成固定浅灰侧栏，研究空间与研究工具清楚分组，8 项功能直接可见；移动端使用抽屉。
- 首页采用编辑式标题和一张真实取自现有演示集的论文速览，再到完整搜索框、主题列表和个人阅读空间。API 模式不显示演示论文冒充真实数据。
- 搜索结果改为编号文章列表；探索页首篇突出，其余双列。文章标题、作者年份、摘要和动作建立稳定层级。
- 阅读页解除大卡片包裹，正文与右侧文献信息分开；收藏、AI、评测、PDF 和审核统一间距、圆角与按钮。
- 简化 AI 页文案和重复技术说明，未配置状态继续禁用发送。
- 保留既有三份 canonical CSS，未增加覆盖样式表、在线字体或依赖。
