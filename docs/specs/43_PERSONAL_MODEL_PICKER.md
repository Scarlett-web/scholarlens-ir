# 个人 API 模型选择 · 2026-11-03

负责人：项目维护者。用户希望填写服务地址与密钥后获取模型，按需加入自己的可选列表，避免猜写模型名称。保留现有玻璃界面、个人配置隔离与手动输入。

## 输入、输出与交互

- 输入个人 HTTPS API 地址与密钥后，点击“获取模型”，复用已认证 `GET /api/ai/models`。无需先填模型；获取列表不发起生成，不自动保存密钥或配置。
- 返回的模型支持搜索与多选，点击“加入可选模型”后进入个人列表。从“当前模型”下拉框选择，保存后用于问答及连接测试。首次添加时选中添加的第一个模型，并明确反馈；已有当前模型不被获取或添加动作替换。
- 可选模型可逐个移除。移除当前模型后要求重新选择，不静默切换。空列表或接口失败时可手动添加模型，错误不阻止已有配置使用。
- `preferredModels` 是个人浏览器偏好的可选增量字段。旧配置的单个 `model` 自动呈现在可选列表中，无需重新配置。不同用户使用各自的偏好键；密钥继续仅存当前标签页的 sessionStorage，不进入可选列表、持久偏好、源码、日志或服务器数据库。
- 修改服务地址时清除旧服务的模型选择及查询结果；修改密钥时清除已获取结果，已保存的可选列表保留，是否可调用由连接测试确认。模型列表不证明该模型支持所选生成协议。
- 获取、测试期间禁止重复请求，卸载时取消请求。用户未点击测试时不产生模型生成。

## 验收

使用隔离浏览器和明确 Mock 的模型服务，验证无模型先获取、过滤与批量添加、刷新后保留、旧配置迁移、账户隔离、手动添加、去重、清除、错误/空列表、地址变化、当前模型移除以及保存后测试使用的实际模型头。Mock 不代表外部服务商的真实模型授权或生成结果。生产构建、前端测试与结构检查通过后部署；不变更数据库、索引、原始 PDF 或模型服务配置。

运行入口：预览服务启动后，设置 `SCHOLARLENS_URL` 指向本机预览，设置 `SCHOLARLENS_PLAYWRIGHT` 为已安装的 Playwright 模块路径，执行 `npm run test:models-browser`。测试拦截全部 API，阻止外部请求，仅使用临时浏览器数据。模型名单、当前模型与密钥的存储边界通过实际界面保存与重新加载验证。
