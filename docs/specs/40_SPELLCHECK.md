# 拼写纠正与输入建议

日期：2026-11-01；负责人：组长。范围为当前jwj的本地4000篇系统，沿用现有ES，不修改数据、索引、向量或账号功能。

输入时约300ms防抖，最多5条真实标题/作者补全及拼写建议；原输入不自动变化。上下键、回车、鼠标均可选择。补全选中可使用候选字段，拼写建议保留原字段及模式。

新增GET /api/spellcheck：q≤200字符，field沿用六字段/all，mode=keyword|hybrid|semantic，year_from/year_to及limit=1..3。返回query、suggestions[{text,field,kind=spelling,matched_count}]。初版semantic/date/authors不纠正，返回空数组。只处理英语字母与空格组成的短查询，最多8词；编号、DOI、短缩写不替换。
原查询在同字段/年份条件下已有BM25命中时不纠正。以ES term suggester在已存在文本字段生成候选，最多改2词，最多验证6个组合，最多返回3条有命中的建议。不是词义翻译或自动改词，也不能保证所有拼错都被识别。

/api/suggest增加可选field，响应保留query/suggestions及原字段；候选增加kind=completion|spelling。原前缀建议不足时请求同一纠正引擎并可用纠正词找真实标题，不编造扩展词。

结果页只在keyword/hybrid原查询成功返回total=0后请求纠正，网络/输入错误不等同于无结果。显示“你是否想搜索…”，点击才改变q，保留字段、mode、年份与排序、page=1。请求期间切换查询必须丢弃迟到响应；失败或无候选不阻断原词搜索。不自动跳转。

验收包括受控单测、真实4000篇错词→建议→点击结果、输入框保持原词、正确词/DOI/缩写/无候选、条件保留和390px截图。输出output/corpus-expansion/spellcheck-08/README.md、验证JSON及截图；本次不自动push或部署。

## 通用纠错增强（2026-11-01）

替换首版偏窄的距离规则：5字母及以上允许2次编辑，3～4字母允许1次；优先纠正索引中缺失的词，最多同时修正3词。失败后再检查索引中存在但搭配错误的词，保留不变词选项，按总编辑距离及词频排序；最多检查36个完整查询候选，返回前必须验证原字段/年份下有结果。
补充漏空格、误加空格候选，仍通过语料验证；不维护针对machine等词的硬编码替换表。
输入建议可提示已有命中词的空格拆合（语料可能本身包含连写词）；结果页仍严格只在原查询无结果时提示，不改变既有结果。
all同时从标题及安全正文词项生成候选，合并去重后仍按同一36候选预算验证，覆盖仅在正文出现的术语。
验收扩大到多个学科词组、漏字/多字/替换/相邻及非相邻换位/多词同时错/空格错误，真实回归记录输出spellcheck-08/generalization/。不承诺覆盖任意错误或中文语义纠错，不改动原检索结果与用户确认流程。
