# 05 UI 规范与页面流程

更新：2026-10-29，按用户最新外观 `d7cfc56` 记录。详细视觉参数见[当前设计](../development/frontend/DESIGN_SYSTEM.md)；本次整理不修改界面或业务实现。

## 1. 当前视觉基线

冰川/海面实景、明亮白玻璃、系统字体和蓝色主操作。桌面使用顶部 Dock；辅助研究工具收进支持悬停和点击固定的菜单。三档材质为纯白通透、标准微霜、凝脂厚雾，新浏览器默认通透，已有选择保留。

使用现有 React 组件、Lucide 图标和 canonical CSS，不把早期“计划引入 shadcn/ui”当成已采用的依赖。桌面优先，已有移动结构只做回归。

## 2. 页面规格

| 页面 | 当前任务 | 状态/边界 |
| --- | --- | --- |
| `/` | 首屏搜索、最多五篇真实最近阅读、3D 装饰 | 空历史不凑满，装饰不制造数据 |
| `/search` | 字段/模式/年份/排序/分页、高亮和作者展开 | 保留 URL 与重试；不显示多余分数提示 |
| `/paper/:paperId` | 元数据、摘要、正文、专注、位置、引用、原 PDF | 主下载为 PDF；缺原件如实显示 |
| `/explore` | 真实候选、换批和字段关系图 | 不是引用图或相似度证明 |
| `/library` | 收藏分类、笔记、历史、备份 | 读取失败不冒充空空间，导入需明确替换 |
| `/account` | 注册/登录、资料、安全、通知 | 所有权和角色由后端校验 |
| `/assistant` | 对话、原文证据、总结/比较、个人 API | 主对话与底部输入，工具按需展开 |
| `/evaluation` | 三级标注、指标和导出 | 未完成标注不出虚假分数 |
| `/upload`、`/admin` | 本地/服务端 PDF、审核和处理 | 本地审批不代表 ES 入库，202 不等于完成 |
| 404 | 返回首页/检索 | 不用 API HTML 回退掩盖错误 |

## 3. 关键交互契约

1. 查询条件进入 URL；切模式或筛选重置页码，不直接比较不同模式 score。
2. 高亮只解释受控标记为文本节点。整标题查询只强调标题，普通关键词和显式字段保留各自范围；分页跳跃明确显示省略号。
3. 长作者列表可展开；论文返回、正文位置和选文笔记保留原有操作，不虚构阅读完成率。
4. 助手支持 Enter 发送、Shift+Enter 换行和输入法防误发；停止保留输入，回答独立滚动，输入区始终可见。
5. 阅读方式、对话记录、API 设置以按钮展开；可关闭、Escape 关闭并返回焦点。读取模型、连接测试和本地保存分别反馈。
6. 通用回答明确“未由本库文献验证”，论文回答保留引用核验；历史消息不充当新论文证据。
7. 当前身份或筛选改变后隔离旧响应；同上下文读取失败保留已知数据和重试。
8. 动效允许全局暂停，遵守系统减少动态；玻璃和装饰不改变论文内容、检索参数或权限。

## 4. 状态与验收

页面需区分加载、空结果、服务不可用、网络失败、无原件、未配置模型和权限不足。关键按钮有提交中/禁用反馈；错误说明失败动作与可做的下一步，不生成替身数据掩盖依赖故障。

应用改动按[QA 清单](../development/frontend/QA_CHECKLIST.md)验证。文档整理仅做链接、路径、结构和保护范围检查，不能因这份规范而声称已经重新执行所有页面回归。历史截图与验收保留日期，当前事实看[状态记录](../operations/STATUS.md)。
