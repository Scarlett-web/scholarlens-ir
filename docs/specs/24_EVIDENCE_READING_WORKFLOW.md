## 输入、输出与不变量

- 输入只来自既有 Agent 的 paper_id、paper_title、chunk_id、quote、locator，以及重新读取的论文标题、摘要和正文。定位只接受后端 `title|abstract|fulltext:chars:start-end` 契约；字符范围是 Python Unicode 码点，前端须正确换算为 UTF-16 偏移。模型引用可以是整个 chunk 中的逐字子串，不能假设 quote 必定等于整个范围。
- 使用明确的“证据列表 + 片段核对”布局，显示所提交的问题、真实证据条数和执行轨迹。证据不再塞入小型聊天滚动窗。来源、字段、字符范围、上下文和动作可见；不编造页码、DOI、出版信息或相关性百分比。
- 选中证据后重新读取原文，只在指定范围内逐字匹配。成功后可查看前后文、复制片段及来源、定位论文中的真实位置、追加至对应收藏笔记。匹配失败、依赖错误和原文变化均明确显示；不得使用模糊匹配悄悄移动位置。
- 原文定位将证据数据放在 URL fragment，服务端不接收片段文本；打开独立阅读页以保留证据台。阅读页仍须重新校验输入，只高亮核对成功的文字。全文中 4500 字符以后的证据自动展开；坏链接不崩溃、不产生虚假高亮。
- 笔记复用已有账户隔离、追加和 2000 字符限制，保留原笔记；容量不足、账户空间未就绪和请求失败不得显示保存成功。核对前不能追加。账户变化或组件卸载时，迟到响应不改变新账户状态。
- 当前问题和当前范围与结果绑定，停止后迟到请求不能替换新结果。保留生成回答、总结、比较、对话和个人 API 配置；无个人 API 时证据检索仍然可用。
- 阅读位置不得因同一帧的布局测量吞掉滚动事件；调整大小和滚动合并时，仍须保留保存意图。阅读位置继续按浏览器与账户隔离，不代表已读完。
- 只修改现有 canonical CSS，不增加前端图形依赖或全局工具，不更改后端接口、数据库 schema、原件、索引或个人供应商配置。
