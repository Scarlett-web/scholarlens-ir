# 助手引用编号与原文查看

日期：2026-11-02。负责人：项目维护者。

## 输入与输出

输入为每条助手消息的原始回答及 API 返回的来源数组（paper_id、chunk_id、论文标题、quote/excerpt、locator）。问答、单篇总结、多篇比较、新消息及已保存对话共用展示组件，不按论文 ID 或标题分支。

输出为正文中的可点击 `[1]`、`[2]` 引用，按该条回答首次出现的片段顺序编号；重复片段共用编号，不同片段分别编号。引用来源列表采用相同顺序，未在正文出现的返回来源排在后面。

点击编号或来源条目打开可关闭的原文窗口，显示该来源的论文标题、完整引用片段、可识别的位置及论文定位入口。支持键盘触发、Escape 关闭和焦点返回；长原文窗口内部可滚动，助手输入区不被正文撑走。位置为空时明确提示，不猜测页码。

只有当前消息返回的来源可建立引用关联，未知标记显示“来源缺失”，不关联其他回答或其他论文。原始消息及后端引用校验不变，不改数据库、论文或索引。复制回答使用相同编号并附来源信息，避免复制内部 chunk 标识。

## 验收

- 多篇任意论文、同篇多片段、重复引用、来源乱序、缺失来源、无引用通用回答均正确展示；历史对话重新打开同样生效。
- 引文和模型文字均作为 React 文本渲染，不执行 HTML；论文链接复用 evidenceHref，不接受模型自造 URL。
- 浏览器受控响应验证点击查看、原文定位链接、键盘关闭、复制、长对话滚动及桌面/移动布局；受控测试不代表真实供应商生成验收。
- 可重复执行：`cd frontend; node --test tests/assistant-citations.test.mjs`、`npm run build`、`node tests/assistant-citations-browser.mjs`（浏览器检查需本地前端及 SCHOLARLENS_PLAYWRIGHT）。预期全部通过。
