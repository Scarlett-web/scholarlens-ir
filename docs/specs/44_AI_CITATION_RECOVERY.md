# 引用生成与有限修复契约

日期：2026-11-03。负责人：组长。

输入为原问题、已核对来源及当前对话；论文内容和模型草稿均是不可信数据。输出继续使用原有 answer/citations/evidence_status 接口。

- 模型可用当轮来源短编号 S1、S2 等引用；服务端只按当轮证据表映射回完整 chunk ID。存储、原文定位与接口引用继续使用原有完整 ID。不得猜测未知编号、改写引文或为错误回答补造引用。
- 引文仍必须逐字出现在对应原文片段内；正文引用必须与引用列表一致；比较仍要求逐篇覆盖。
- 校验失败最多修复一次。修复轮收到上一轮草稿及服务端生成的安全错误分类；草稿不得当作新证据，不进入成功响应或日志。修复失败继续保留证据，不发布不合格答案。
- 无论文范围的纯问候直接进入现有通用回答流程；研究问题、混合问候和带范围问题仍走研究流程。

验收：短编号映射和未知编号拒绝；伪造引文继续失败；修复轮携带草稿与错误且不泄露；纯问候不调用检索；原有比较、权限、会话与预算测试通过。真实模型验收需另行记录，受控测试不能代替。
