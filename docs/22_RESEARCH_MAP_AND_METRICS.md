# 研究关系图、书架与评测图形契约

负责人：项目维护者。依据 GPT Pro 记录的探索、文献库和评测建议，继续完成逐页设计；不新增后端索引、数据库迁移或图形依赖。

## 输入、输出与边界

- 探索：输入当前接口返回且符合筛选的至多 20 篇真实候选；默认保留列表，可切换关系图。节点为论文，连线只来自规范化后完全一致的作者姓名、关键词、主题标签或机构名称，逐条显示依据。相同姓名不证明同一人，不推断引用、影响力、语义相似度；节点大小只表达本图连线数。无匹配字段时保留孤立节点和明确空关系状态，不生成装饰边。选择、键盘操作、详情链接、局部关系与轻微视角拖动均可用；全站暂停和系统减少动态效果时保持静态。
- 文献库：保留分类、笔记、备份和历史功能；展示当前浏览器、当前账户分区中真实保存的阅读位置。收藏快照没有全文，因此仅显示“上次记录”，打开原文后仍按文本长度验证旧位置。将笔记摘要和阅读状态并列展示，空状态呈现研究书架。
- 评测：现有 Precision/nDCG 算法口径保持；只有相关前缀完整标注后绘制对应指标，未就绪使用“待标注”而非零分。补充完成率进度、0/1/2 文字和颜色反馈，以及本页实际 API 请求的耗时记录，禁止随机波形或虚构实验数据。损坏存储中的非法标注不能产生有效指标。
- 资源与交互：关系组件按需加载，采用 HTML/SVG 与 CSS 深度，不运行常驻物理模拟；保留列表效率、系统字体、现有图标及 canonical CSS。桌面优先，390px 做布局回归。

## 验收条件

关系算法测试必须覆盖精确字段依据、孤立节点、重复 ID、未知占位值、稳定布局和候选上限；指标测试覆盖非法本机标注。运行 build、前端测试、结构检查，以及真实 API 游客浏览器回归。浏览器检查列表/图切换、节点/关系详情、筛选与换批、位置与笔记可读、评测未标注/部分/完整状态、减少动态效果和桌面/390px 几何。实际查看截图。仅临时游客空间写入验证数据，不注册或改写生产账户。

验证后同步交付仓库，提交推送并部署既有华为云服务，校验资源哈希、只读检索及 PDF。原件、用户、索引、模型、环境和其他服务保留；不将本批设计当作总审计完成。结果与发布记录在完成后追加。
