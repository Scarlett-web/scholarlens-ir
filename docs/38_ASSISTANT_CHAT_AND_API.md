# 助手对话页与个人 API 修订

日期：2026-10-29。负责人：当前项目维护者。输入、输出和验收契约见 [个人 AI 配置](10_RELEASE_AND_PERSONAL_AI.md)。

本次保留明亮白玻璃、冰川背景和原有玻璃通透度，重新组织助手页：聊天成为主体，阅读方式、对话记录、API 设置改为工具按钮，单个面板按需展开。回答独立滚动，输入框保持在下方。增加 Enter 发送、Shift+Enter 换行、输入法防误发和复制回答；保留停止、原文检索、论文选择、总结、比较、对话保存与引用核对。

个人 API 支持 Chat Completions 和 Responses，旧配置按 Chat Completions 处理。Responses 同时用于检索规划与回答，明确关闭供应商存储。用户可以先读取模型列表，选择模型，再测试一次简短真实生成；保存本地配置与连接成功分别提示。密钥仍仅在当前账户、当前标签页会话生效，退出清除，不进数据库、源码、构建变量或服务器全局环境。

截图中的 `gpt-5.5` 经实际请求返回 404，提示已退役；当前模型列表含 `gpt-6.1-sol`。程序对模型或路径不存在给出独立错误，不再让用户调整问题格式，也不自动替换模型。个人长回答单次读取超时至少 60 秒，总 Agent 预算仍为 120 秒；连接测试限 25 秒。

本轮验证范围：

- 前端生产构建、38 项单元测试、结构校验；独立 Chrome 检查工具开关、Escape/焦点返回、配置与会话密钥、模型列表/测试提示、输入法/换行、长回答、复制、停止、上游认证失败不退出、真实证据和对话增删。1440×900 / 1366×768 回答区为 475 / 343px，输入区在首屏；390px 无横向溢出。
- 后端协议与个人配置测试覆盖规划/回答两种协议、完成状态、非文本和畸形响应、引用校验、认证/404/限流错误、DNS 固定及私网拒绝、凭据脱敏、请求隔离和测试不落库。
- 华为云使用应用代码及独立临时账户库，按用户授权进行少量真实供应商调用：读取 26 个模型，`gpt-6.1-sol` 在两协议下均成功生成；自然语言问题得到 10 字通用回答且无伪造引用；单篇总结得到 1052 字回答，3 条原文引用通过校验，规划、检索、原文核对和引用检查均完成。该结果仅证明本次所用接口与模型；模型列表和可用性可能随后变化。
- 真实库回归保留 859 篇、六字段高亮、整标题仅标题高亮、更多作者、语义/混合检索、原 PDF 下载。账户安全在独立本地 fixture 检查，原账户和正式数据未参与写入。

曾观察到本机 Windows Python 直连供应商时连接重置；华为云 HTTPS/DNS 固定连接正常。本轮真实供应商验收来自服务器，不能据此宣称所有本机网络均已修复。截图中的长回答验收使用明确标记的替身内容，真实供应商结果另有脱敏记录；未保存用户密钥。

交付按持续授权推送 `origin/zjl` 并部署既有华为云服务。部署保留上一 release、SQLite 一致性备份和环境副本，仅重启本应用；发布编号和公开资源验证将在部署后补充。
