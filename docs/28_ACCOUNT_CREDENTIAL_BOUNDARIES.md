2026-10-28。负责人：项目维护者。本轮对应全局审计中的认证、退出、会话失效和用户隔离。桌面优先，390px仅检查回归；不改变当前视觉方向。

## 已发现的问题与验收契约

修改密码或停用账户时，服务端先验证登录会话，再核对当前凭证。旧实现将这两种失败均标为 `401 unauthenticated`，前端收到任何当前令牌的401便清除登录状态及会话个人密钥。因此输错当前密码也会被迫退出，而服务端会话仍有效。

- 会话有效、二次确认错误：保持HTTP401兼容，返回 `invalid_credentials`；页面提示原错误、允许重试，不退出或清除个人配置。接口不修改任何账户或会话数据。
- 令牌缺失、过期、已撤销或用户停用：仍为 `unauthenticated`。客户端清理当前登录和会话个人密钥，回到游客状态；旧请求不能清理后来建立的新会话。
- 修改成功：撤销该用户所有设备会话，旧密码不能登录，新密码能登录；收藏和笔记保留。
- 停用成功：撤销全部会话、禁止登录，保留用户及个人数据；其他用户不受影响。最后一个有效管理员的保护保留。
- 写入验收只使用脚本新建的临时SQLite和生产账户/工作区路由。独立浏览器检查真实HTTP与界面，不注册或修改生产账户。隔离服务以随机端口和逐次实例挑战标识自身；测试工具不接受外部目标或复用线上代理。

## 验证方式

后端隔离测试覆盖凭证失败、真实失效、用户隔离和成功撤销。浏览器工具自行启动本机隔离账户服务并挂载当前生产构建，验证登录、错误恢复、配置保留、资料与文献持久化、跨用户隔离及退出清理。所有账户、论文、配置标记均明确为测试夹具；不连接Elasticsearch、邮件或真实供应商。

```powershell
$accountTestTemp = 'tools/audit/reports/account-credentials-' + (Get-Date -Format 'yyyyMMdd-HHmmss')
backend/.venv/Scripts/python.exe -m pytest backend/tests/test_account_credentials_isolated.py -q --basetemp=$accountTestTemp
node tools/audit/account-security-browser.mjs
```

报告、截图及独立测试运行目录写入忽略目录 `tools/audit/reports/`；测试令牌、密码和模拟个人密钥不得写入报告。整体审计目标保持原范围，本轮通过不代表供应商实际生成、生产账户跨设备写入或全部安全审计已经完成。
