# 搜索记录流与账户入口契约

2026-10-28；负责人：项目维护者。参考 GPT Pro 逐页建议中的搜索工作台与账户空间，延续主流程“搜索 → 阅读 → 保存和标注”，保留现有后端、真实论文与个人 API 边界。

## 输入、输出和约束

- 搜索条件以现有 URL 为准。结果行使用实际返回的论文 ID、年份、标题、作者、摘要/高亮和关键词；年份缺失明确说明，不推断论文类型、引文关系、百分比相关性或下载可用性。后端评分仅作为原始检索分数表达，不能冒充置信度。
- 搜索结果使用编号、年份、正文和动作形成记录行；在同一行发现阅读、收藏和单篇原文证据入口。保留分页、排序、分享、搜索字段、语义/混合检索、空白浏览候选边界以及错误重试；不改变现有 URL 或检索语义。
- 已选条件直接可见并可逐个移除，变更回到第一页；关键词、字段、模式和年份各自有明确动作。结果数与实际服务器耗时可见；无结果或加载时不显示旧数据。未知数据不显示为零或“已完成”。
- 登录页保留清楚的输入和原有账户能力，在左侧用三层文献与真实功能形成克制的玻璃视觉。聚焦反馈表达进入表单，不制作虚构论文或阅读统计；减少动态效果与站点暂停均需生效，桌面优先。
- 账户搜索历史须区分读取中、失败、真正空记录和有记录；失败保留重试入口，不能显示“还没有搜索记录”。翻页与清空时，旧请求不得重新写回；账户变化时旧数据清空。保留原有登录/注册/退出、资料、安全、通知、角色功能，不新增供应商配置。
- 个人资料、通知、管理账户列表的读取分别显示加载/失败/重试，不把未知数量显示为零；读取错误不污染其他设置分组。资料表单编辑不重复下载头像，实际上传新头像后刷新；原有权限与写入动作不改变。
- 所有样式修改 canonical CSS，不增加覆盖样式表、字体、图形依赖或全局工具。生产不新增测试用户、笔记或原件，不运行写索引验收。

## 验收条件

运行生产构建、前端单元与结构检查，以及同一交付构建的真实 API 游客浏览器回归。独立本机 Chrome 使用明确拦截的 API fixture 验证条件移除/参数、记录行链接与收藏、历史加载失败/恢复、分页和清空的迟到请求隔离、账户失效和登录表单。桌面截图为主要视觉验收，390px 仅布局回归。fixture 不代表真实认证或账户持久化通过。

验证后推送并部署既有华为云服务，保留旧 release、一致性数据库和环境备份；公网核对资源、真实检索与游客页面，按实际证据追加记录。其余安全检查、供应商生成和逐页未完成事项继续保留。

## 实现与验证结果

- 搜索结果改为编号/年份、标题与片段、阅读/收藏/单篇证据动作三列记录。缺失年份显示“未提供”，只有后端标记可用时显示 PDF 原件状态；评分保留真实零值，仅展示原始检索分数，不画虚构的相关性百分比。所有原有检索模式、排序、分页、分享与阅读链接保留。
- 关键词、字段、非默认模式与年份条件可见，逐个移除会回到第一页并保留其他参数。空白查询仍明确是最多 20 篇候选选读，不把候选总数写成全库数量。无新增不受后端支持的筛选字段。
- 登录页左侧用三层功能文献条、边缘光和表单聚焦反馈表达研究空间；表单仍为清楚稳定的浅色表面。没有假论文/假统计、额外字体、图形依赖或新 CSS 层。站点暂停可停止层叠变化，系统 reduced motion 停止动画。
- 搜索历史拆为独立账户组件，加载、错误、真正空记录和清空过程分开；加载失败不再被显示为“还没有搜索记录”。分页请求可取消，清空先废弃旧请求并使用序号隔离迟到结果；清空失败显示错误并允许重新读取。账户过期卸载旧私有组件。
- 资料、通知与管理员列表分别维护读取状态和重试，错误只出现在对应分组，未知数量显示破折号。编辑资料不会因为 profile 对象变动而重新下载头像，实际上传成功后刷新头像；取消和对象 URL 清理保留。资料保存、通知已读、管理员角色更新、安全和停用入口保留，不修改后端授权规则。
