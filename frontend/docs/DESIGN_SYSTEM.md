# ScholarLens · 冰川观测站设计规范

本版采用作者 elayadesign 的两套设计 Skills 的检查方式：
- .agents/skills/redesign-existing-projects/SKILL.md — 现有网页诊断、组件和状态精修
- .agents/skills/landing-page-design/SKILL.md — 首页主动作、排版、留白与几何规则

源项目：https://github.com/elayadesign/ai-design-skills 与 https://github.com/elayadesign/redesign-skill

两套 Skill 的默认规则偏向营销落地页。ScholarLens 是学术检索产品，所以保留用户指定的 Apple / macOS 轻盈浅色方向，以及真实可操作的检索、阅读、收藏、评测与本地 PDF 工作流。不会添加虚构的学术数据、指标、口碑或 AI 回答。

## 核心体验

- 首屏唯一主任务：按关键词、作者、机构或全文开始论文检索。
- 主要导航：首页 / 论文检索 / 探索论文 / 我的文献。
- 次级工具：检索评测 / PDF 工作区 / 审核工作台 / AI 助手（桌面侧栏直接可见；手机端在抽屉导航中；原有三项工具保留页内导航）。
- 首页以编辑式标题和明确标注的演示论文速览构成首屏，下方是横跨内容宽度的搜索，再到主题列表与阅读空间；去掉重复的流程介绍和工具链接。
- 检索结果采用带顺序编号的单一文章列表和轻分割线；探索页首篇突出，其余用双列轻面板供浏览。
- 所有不可用功能明确说明原因；AI 服务地址、模型和密钥仍留空。

## 设计 Tokens

| 语义 | 值 | 说明 |
|---|---|---|
| Canvas | #EDF4F8 | 冰蓝画布与本地实景背景 |
| Surface | rgba(255,255,255,.94) | 阅读纸面；导航与首页透明度更高 |
| Text | #193348 | 正文标题 |
| Muted | #506779 | 辅助信息 |
| Hairline | rgba(70,109,134,.16) | 容器边框和列表分隔 |
| Accent | #0969A9 | 强调主动作、链接与选中 |
| Accent soft | #E1F1FB | 轻强调背景 |

圆角值优先：8 / 12 / 16 / 24 px。主控件 8 px；面板 16 px；特殊首页场景可 24 px；内外嵌套遵守视觉同心原则。

间距值优先：0 / 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 px。

字号优先：12 / 14 / 16 / 18 / 24 / 30 / 36 / 48 / 60 px。正文默认 14–16 px，辅助文字最低目标 12 px；搜索结果标题 18 px；首页标题 48 px（手机 36 px）。

字体：系统 SF Pro / Segoe UI / PingFang SC / 微软雅黑优先。不依赖在线下载字体，尊重用户指定的 Apple 产品风格；数字可用等宽数字。

Motion：使用 cubic-bezier(.22,1,.36,1) 自定义缓动；按钮颜色变化 300ms，按下轻微缩放，系统减少动画偏好时禁用装饰过渡。不使用大面积跳动。首页允许可暂停的轻微循环装饰：CSS 3D 层叠纸张、8 秒上下浮动和 26/34 秒轨道；持续装饰离屏暂停，减少动态偏好下完全静止。鼠标视差限制在小角度，使用事件驱动 requestAnimationFrame 合并更新，没有持续 JavaScript 渲染循环。内容入场 500–700ms，位移 8–24px；列表进入视野后逐项出现。按钮可使用短暂点击波纹，收藏图标有一次反馈，侧栏图标和探索卡片有悬停反馈。全站暂停设置持久保存，并取消运行中的 Web Animations。

## 布局与视觉优先级

应用框架：桌面外边距 24px，侧栏与主区接成同一框架。224px 固定侧栏在 1240px 以下为 208px，960px 以下保留原移动抽屉。整片玻璃在 shell 的独立伪元素绘制，共用 6px 背景模糊与轻反光，避免重复磨砂。首页主区透明、工作区增加 .38 白底、阅读区增加 .68 白底；正文保持纸面。顶部保留面包屑与数据状态。短于 800px 的桌面窗口压缩导航间距并隐藏装饰署名；侧栏保持可滚动，使用细滚动条。

首页：冰川实景透过玻璃、左侧编辑式标题和装饰性知识连线，右侧是实际最近阅读最多五篇的翻页卡片，下面是完整查询框。最近阅读按浏览时间排序并去重，不用未读的演示论文填满。下方用主题列表与阅读空间编排。示例词轻量显示，不抢夺搜索操作的视觉权重。

论文检索：左侧筛选 192px（1240px 以下 176px），右侧连续文献列表。文章标题最大优先，作者与年份第二，摘要在正文大小，关键词用普通文字呈现，减少彩色标签。检索方式和数据说明采用渐进披露，手机端筛选默认收起。重要按钮跟随任务而非漂浮。

阅读页：标题与正文分别使用高不透明白色纸面，降低照片对长文阅读的干扰；元数据置于右侧轻玻璃信息栏，保留原有单列适配。

我的文献：收藏与历史两个入口，本地备份在右；本地存储提示缩为一行，手机端分类默认收起。“所有文献”表示全部分类，“未分类”对应原有默认分类，仅更改显示名称，存储键不变。空列表保留检索与探索操作。

工具页：轻提示条说明“本地”与“正式索引”的数据边界，保留可用的页内切换。

未知路径：显示自有 404 页面，帮助回到搜索或首页。

## 最近阅读卡片与本轮范围

本轮以电脑端为验收重点。卡片包括空状态、实际页数、前后按钮、直接跳页、7 秒自动翻页与暂停。悬停和键盘焦点暂停轮播，离屏或隐藏页面暂停轮播。自动翻页不新增阅读记录；只有真正打开详情页才更新浏览记录。清空/移除原浏览记录后，卡片按剩余记录重新显示。系统减少动态或用户暂停网站动效时，手动换页即时生效。

卡片保持固定内容高度，长标题最多两行、全文通过详情打开，缺失作者/摘要给明确占位说明。保留 3D 深度，但交互控件不能被父层遮挡；以真实指针点击与键盘操作验收。

## 冰川材质与交互补充（2026-10-27）

真实背景来自摄影师 X1ntao ZHOU 的杰古沙龙冰河湖照片，经本地压缩为 3200×1801 WebP（716,302 字节）；来源与许可见 public/images/SOURCES.md。导航、搜索和个人阅读空间使用细白边、克制阴影与背景模糊；弹窗和选项面板接近不透明。未增加 WebGL、动画依赖或运行时外部图片请求。

局部玻璃高光由鼠标事件驱动 requestAnimationFrame 合并更新，只改变高光位置，不移动按钮。全局暂停、系统减少动态、页面隐藏与卸载会清理高光。保留 3D 阅读卡片及真实最多五篇记录；不支持 backdrop-filter 的浏览器使用较实的底色。

## 通透材质修订（2026-10-27）

根据用户截图反馈，取消侧栏与主区之间的悬浮间隙，移除搜索外框、主题及个人阅读空间的独立卡片底色/描边/阴影，移除两块非功能性研究浮签。仅搜索输入保留玻璃控件，最近五篇保留 3D 纸张。局部高光仅用于搜索及顶部导航。小字改为更深的蓝灰色，平衡透景与可读性。见 archive/20261027-28/UI_CLEAR_GLASS_20261027.md。

## 整体体验修整（2026-10-27）

电脑端顶部状态栏随页面滚动；搜索保留在左侧首屏，与右侧真实最近阅读卡片并排。搜索筛选与收藏分类在页面滚动时贴近顶部 24px。标签页显示当前页面或论文题名。PDF 使用浏览器原生模态窗口，打开进入焦点、关闭后回焦，背景不可交互且暂停滚动；视觉仍为已有纸面窗口与玻璃遮罩。证据与回滚见 archive/20261027-28/UI_AUDIT_20261027.md。
