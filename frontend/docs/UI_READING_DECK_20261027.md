# 最近五篇阅读翻页与桌面动效升级

## 用户需求与范围

用户要求增加动态效果，并让首页右侧卡片展示自己最后看过的五篇论文，不足五篇按实际数量显示。后续明确只关注电脑端。本轮沿用现有浅色研究工作区和两套项目设计 Skills。

## 最近阅读

复用原来的浏览记录，不另建一份历史。按浏览时间从近到远排序、论文 ID 去重后取前五篇。自动翻页不会记录一次新阅读，真正打开详情后才沿用现有 recordView 更新历史；原有最多 50 条历史及备份行为保留。同一浏览器新标签页打开论文时，通过 storage 事件同步更新首页记录；已用两标签页实际验证，不涉及跨设备或账户同步。

零条显示空状态，一条只显示一页并禁用前后按钮，二至五条按实际数量生成页码。超过五条只展示最近五篇。支持 3D 纸张翻页、前后按钮、直接跳页、键盘方向键和 7 秒自动换页。鼠标悬停、键盘焦点、离屏、页面隐藏、用户暂停动效、系统减少动态均会阻止自动轮播。暂停运动时仍能手动换页。演示论文继续标注虚构内容，不用未读数据补满。

修正 3D 容器扁平化导致控件命中区域被父层遮挡的问题，保持 preserve-3d 层级，并在鼠标靠近链接/按钮时停止更新视差。长标题最多显示两行，可打开详情阅读完整标题和正文。

## 其他动态

新增装饰性知识连线与节点、列表和信息区滚动入场、按钮点击波纹、侧栏选中/悬停反馈、搜索聚焦抬升、收藏图标反馈与探索卡片悬停。支持 CSS 滚动时间线的浏览器显示页顶滚动进度。

网站动效开关位于侧栏，偏好写入新增的 scholarlens-v1:motion-paused 键，不更改旧数据格式。系统减少动态效果优先；关闭动效会取消共享 Web Animations，内容无需动画也可见。未添加依赖、在线字体、外部媒体或覆盖 CSS 文件。

## 验证

最终构建、6 项单元测试、结构检查和完整浏览器回归通过。新增隔离浏览器用例验证 0–6 条真实访问记录、去重排序、刷新持久化、翻页和全局偏好。额外桌面检查实际自动翻页、真实指针连续点击、详情链接、方向键焦点保留、减少动态下手动换页。

桌面截图在 output/playwright/deck-*。本轮测试访问的是明确标记的演示论文，不会写入用户浏览记录。真实 FastAPI / Elasticsearch、真实 AI 和课堂投影不属于本轮验证。
