# ScholarLens V2 功能范围

本轮以真实前端交互闭环为标准，避免用按钮与空卡片冒充功能。

| 模块 | 前端可操作功能 | 数据保存 | 后端限制 |
|---|---|---|---|
| 搜索 | 六字段 + 全字段、最近搜索、建议、年份范围、排序、分页、分享 URL、高亮、重试 | 查询历史在 localStorage | Demo 只做字符串匹配，真实 BM25 待接 |
| 论文 | 摘要、全文查找和展开、引用格式/复制/导出、收藏、相关文章 | 浏览历史在 localStorage | 在线 PDF 依赖真实服务 |
| 探索 | 领域计数、关键词过滤、排序、换一批 | 不单独保存 | API 模式只做首批结果筛选，不是推荐算法 |
| 我的空间 | 文件夹创建/重命名/删除、逐篇分类、笔记、查询、排序、历史、备份恢复 | localStorage | 无账号同步 |
| PDF 工作区 | PDF 头和大小校验、SHA-256、存原文、预览与删除 | IndexedDB + localStorage | 无真实上传、解析或索引 |
| 审核 | 筛选、搜索、看原文、写意见、通过/拒绝/恢复、删除 | localStorage | 无服务端角色权限，不能当作正式审批 |
| 检索评测 | 查询、三级人工标注、Precision@k / nDCG@k、导出 | localStorage | 真实基准和 Recall 未完成 |
| AI | 自定义后端 JSON 请求、停止、清空、错误状态、引用回链 | 不保存会话 | 默认端点为空，不能产生假答案 |
| 展示模式 | 放大搜索结果与正文 | localStorage | 需现场投影测试 |

## 禁止混淆

不能把虚构论文当作真实学术论文；不能把模拟排序称为 BM25；不能把本地审批称为真实入库；没有证据不得造检索评测分数；没有后端 API 时不得生成 AI 回答。
