## 发现并修复

1. 搜索筛选与收藏分类保留了旧吸顶栏的 112px 顶部偏移，取消顶部吸顶后出现过量留白。两处改为 24px。实测检索页滚动后筛选面板 top=24。
2. 所有标签页都显示相同标题，多个页面与论文难以辨认。框架按当前页面更新标题，论文加载后显示实际论文题名；404 显示页面未找到。
3. PDF 预览原本只是带 aria-modal 的普通容器，打开后焦点仍在背后按钮，Shift+Tab 可进入背景。改为原生 dialog.showModal()，自动聚焦关闭按钮，补充 Tab 边界处理，关闭后回焦原按钮；背景不可交互、停止滚动，关闭时恢复原有 overflow 与 padding。下载、关闭按钮和遮罩点击保持可用。

只维护既有 canonical CSS；不新增依赖，不改变存储格式、业务 URL、论文数据与 AI 配置。
