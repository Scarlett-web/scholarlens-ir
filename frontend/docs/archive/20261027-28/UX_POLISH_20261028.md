# 桌面使用体验调优

用户要求：登录页更美观，改善多个功能的操作体验，消除模板化页面。沿用现有冰岛照片、清澈玻璃、浅色研究工具风格。负责人为本次维护者。

输入为当前源码、实际页面和真实 API；输出为登录入口、账户设置、论文助手、文献整理、检索评测及文件入口的本地修改。优先让主要操作在首屏可见，减少大段说明、重复导航和装饰性标题。保留既有 URL、数据隔离、全部账户操作、本地 PDF 和真实检索功能。

本轮不发布、不改变用户数据、索引、原件或真实供应商配置。测试只创建专用 QA 账户并按原接口停用，不赋管理员权限。对现有文件先备份，原子替换，并按清单同步到本地交付目录。

验收：build / unit / structure；浏览器检查登录、注册、密码显示、账户设置分组、收藏笔记、未配置 AI 时的真实证据检索、评测标注及 PDF 工作区。主要检查桌面首屏和操作反馈，390px仅回归。不把静态构建或模拟数据当作真实业务成功。

## 已完成修改

- 登录入口改为左右布局，表单独立限宽；用户名规则只在注册时显示，提供密码显示切换、大写锁定提示、提交中反馈。核验会话时显示加载状态。从助手或上传入口登录后返回对应页面，返回地址限于站内已知路径。
- 账户页面按个人资料、账户安全和通知分组；管理员账户仍保留管理分组。个人资料用双列表单，搜索历史折叠，单页记录不显示无用分页。所有原账户请求和权限校验保留。
- 论文助手改为主工作区和设置侧栏。未配置个人 API 时直接提供真实原文证据检索；总结和比较明确提示配置依赖。输入与主要按钮在 1366×768 首屏内，证据在内容区内滚动且从第一条开始显示。对话新建、重开、删除及个人配置隔离保留。
- 文献页修正登录账户的笔记保存位置、保存中和失败反馈；区分分类为空与全库没有收藏；历史清空确认和反馈按账户或游客区分。
- 评测页收起方法说明，移除重复工具导航与英文步骤装饰。人工标注、计算边界和 JSON 导出保留。
- 上传页简化实现细节文案，明确账户上传与本机文件边界；读取上传记录时显示状态，不再将加载中误报成空队列。审核权限和 DOCX 转换条件保留，未错误禁用待审核上传件的原件转换。
- 修复开发模式的账户初始化竞争：每次读取阅读空间使用独立存活标记，已失效的初始化响应不能覆盖新收藏或阅读历史。真实浏览器曾复现历史为空，修复后开发和生产构建验证均通过。

仅编辑既有 canonical CSS，不新增覆盖样式表、字体或依赖。保留冰岛照片和原有玻璃框架。
