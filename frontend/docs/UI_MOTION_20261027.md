# ScholarLens · 3D 与动态细化

用户希望通过 3D 和动画吸引注意，同时保证页面精美、功能完整。本轮继续沿用项目内设计 Skills 和 Apple / macOS 浅色规范。

## 效果

首页将原文献速览改成 CSS perspective + preserve-3d 的层叠纸张，保留现有论文内容与可点击链接。轻微浮动、细线轨道和“发现线索 / 连接知识”浮签表达研究主题，不含虚构统计或推荐声明。鼠标位移只产生小角度视差。

标题与搜索短距离错峰入场，下方阅读空间进入视野后只入场一次。主题箭头、主按钮和探索卡片提供轻微反馈，正文与搜索结果保持安静。

## 可用性与开销

- 桌面提供暂停/恢复装饰动画与视差的按钮。
- 场景离屏或页面隐藏时暂停循环；指针事件按帧合并，无常驻 JavaScript 渲染循环。
- 手机隐藏 3D 装饰及暂停按钮，不改变搜索、导航、文献操作。
- `prefers-reduced-motion: reduce` 下停用动画与视差，并支持运行时偏好变化。
- 未增加依赖、在线字体、外部媒体或 WebGL。沿用三份 canonical CSS，没有新增覆盖样式表。
- 新视觉没有改变 URL、数据服务、本地存储和 AI 配置。

## 本地验证

构建、6 项指标单元测试、结构校验、完整浏览器功能回归通过。独立 Chrome 检查了鼠标视差、暂停/恢复、离屏暂停、减少动态偏好，以及 1024–1920px 桌面宽度。390×844 移动设备模拟检查首页、搜索、探索、收藏布局。

截图在 `output/playwright/motion-*`；`research-scene-motion.gif` 是实际浏览器截图序列合成的局部预览，不是性能测速或完整实时录像。尚未验证真实手机帧率和教室投影效果。
